POZFILES — ФАЙЛОВЫЙ МЕНЕДЖЕР ДЛЯ ANDROID TV (Compose for TV)
==========================================================

Экран:
- слева: накопители (внутренняя память, USB) с полоской заполнения,
  сеть (найденные DLNA-серверы, сохранённые SMB-папки, «Обновить»,
  «Подключить папку SMB»), внизу оперативная память и кнопка «Освободить»;
- справа: файлы текущей папки и путь сверху.

Пульт: OK — открыть, Назад — на уровень вверх → в меню → выход.
Долгое OK на SMB-сервере — изменить или удалить.

Что чем открывается:
- видео и музыка — встроенный плеер (Media3), в т.ч. потоком с DLNA и SMB;
- фото — встроенный просмотр (←/→ — соседние фото в папке);
- APK и документы с накопителей приставки — системой (внешним приложением).

Где что лежит (app/src/main/java/com/poz/files/):
- MainActivity.kt ...... связь с системой: разрешения, USB, открытие файлов
- FilesScreen.kt ....... экран: меню слева и список файлов
- Components.kt ........ строки, полоски заполнения, заголовки
- Browser.kt ........... где мы сейчас и что загружено
- Model.kt ............. источники, файлы, типы файлов
- Device.kt ............ накопители, место, оперативная память
- Dlna.kt .............. поиск DLNA (SSDP) и просмотр папок (UPnP)
- Smb.kt ............... SMB через jcifs-ng и чтение видео для плеера
- PlayerActivity.kt .... встроенный плеер
- ImageViewer.kt ....... просмотр фото
- SmbDialog.kt ......... окно подключения SMB
- Theme.kt ............. цвета, формы, шрифт Inter

targetSdk = 28: так приложение получает обычный доступ ко всем файлам
после одного разрешения «Файлы и медиа».

SMB-логины хранятся в настройках приложения на приставке (не зашифрованы).

Сборка: Build -> Generate APKs (вариант release).
Готовый файл: app/build/outputs/apk/release/app-release.apk
